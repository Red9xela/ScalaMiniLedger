# Scala Mini-Ledger

Потокобезопасное in-memory ядро расчётного сервиса (бухгалтерской книги) на **Scala 3** для управления банковскими счетами и денежными переводами.

## Функциональность
- Создание счетов с поддержкой валют (`RUB`, `USD`, `EUR`) и статусов (`Active`, `Frozen`, `Closed`).
- Пополнение счёта (`deposit`) с валидацией суммы, статуса счёта и валюты.
- Атомарный перевод средств между счетами (`transfer`) с защитой от гонок данных (Race Condition) и взаимных блокировок (Deadlock).

## Стек и ключевые концепции Scala 3
- **Scala 3.3+**, **sbt**, **ScalaTest**.
- **`opaque type`** (`AccountId`) — строгая типизация идентификаторов без накладных расходов на упаковку (boxing) в рантайме JVM.
- **ADT (`enum` и `case class`)** — моделирование предметной области и бизнес-ошибок (`LedgerError`).
- **Функциональная обработка ошибок** — использование `Either[LedgerError, A]` и `for-comprehension` вместо выбрасывания исключений (`throw`) и `null`.
- **Потокобезопасность** — хранение состояния в `ConcurrentHashMap` и пессимистическая синхронизация с упорядочиванием блокировок (Lock Ordering) по ID счёта.
